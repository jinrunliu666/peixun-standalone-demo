# 独立培训演示项目

本项目基于本人参与开发的某 OA 系统中的培训模块，经过整理和修改，形成独立的培训前端演示项目。它仅保留培训相关页面和交互，不包含原系统的登录、其他业务菜单、后端接口或真实业务数据。演示身份固定为“演示用户 / 技术部”，首次打开会载入虚构测试数据。

技术栈：Vue 3、Vite、JavaScript、CSS、Lucide 图标。本仓库是独立演示实现，不代表原 OA 系统的完整技术栈或生产功能。

## 运行

需要 Node.js 18+ 和 npm。在项目目录运行：

```bash
npm ci
npm run dev
```

按终端显示的本地地址打开浏览器。`npm run build` 可验证生产构建。

## 数据说明

内置两家演示公司、五名虚构人员，以及课程、培训计划、考试、题目、证书、账单、通知和错题。公司、部门、人员筛选会作用于对应列表；分配给“演示用户”的内容出现在“我的学习”。测试数据及后续在“功能管理”中的修改只保存在当前浏览器的 `localStorage`。右上角“重置测试数据”可恢复初始内容，但会清除当前浏览器中的演示修改。演示内容不会发送到公司服务。请勿在演示表单中输入真实员工或业务数据。

目前课程、考试和计划支持列表、筛选及基础状态演示；计划支持申请和验收。考试按钮只模拟完成状态，不包含正式的答题与评分逻辑。题库、证书、账单提供本地录入和管理；报表仅展示基础数量统计。没有文件上传、支付或通知发送功能。

这个演示项目没有服务端鉴权与多用户隔离，不适合直接用于真实业务。本仓库不包含原 OA 系统的源代码仓库、历史提交或真实数据。
